# Lưu dữ liệu ra file

Tài liệu này quy ước cách lưu dữ liệu ra file (yêu cầu File I/O của đề: lưu sản phẩm, khách hàng, giao dịch). Các thẻ lưu/đọc từng loại dữ liệu đều theo quy ước này.

## 1. Cách lưu

Lưu dạng **binary** bằng Java serialization (`ObjectOutputStream` / `ObjectInputStream`). Mỗi file chứa nguyên danh sách đối tượng của một loại dữ liệu. Các lớp được lưu (`FoodProduct`, `Customer`, `Order`, `OrderDetail`, `ReturnOrder`, `ReturnDetail`, `StockMovement`) phải `implements Serializable`.

## 2. Các file

Tất cả nằm trong thư mục `data/` ở thư mục gốc dự án (đường dẫn tương đối so với thư mục chạy chương trình, NetBeans mặc định là thư mục dự án).

| File | Nội dung |
|---|---|
| `data/products.dat` | Danh sách sản phẩm |
| `data/customers.dat` | Danh sách khách hàng |
| `data/orders.dat` | Danh sách đơn hàng (kèm các dòng hàng) |
| `data/returns.dat` | Danh sách phiếu trả hàng |
| `data/stock_movements.dat` | Lịch sử thay đổi tồn kho |

## 3. Khi nào đọc và ghi

- **Đọc** một lần khi khởi động chương trình, trước khi hiện menu.
- **Ghi** ngay sau mỗi thay đổi thành công (thêm, sửa, xóa, bán hàng, trả hàng, đổi tồn kho), để dữ liệu không mất nếu chương trình bị tắt đột ngột.

## 4. Xử lý lỗi

- File chưa tồn tại (lần chạy đầu): coi như chưa có dữ liệu, thư mục `data/` và file được tạo khi ghi lần đầu.
- File không đọc được hoặc bị hỏng: in thông báo và chạy tiếp với dữ liệu rỗng, không làm chương trình dừng.
- Lỗi khi ghi: in thông báo lỗi, chương trình vẫn chạy.

## 5. Công cụ dùng chung

`helper/FileHelper`:

- `save(String fileName, Object data)`: ghi một đối tượng (thường là danh sách) ra file.
- `load(String fileName, T emptyData)`: đọc đối tượng từ file, trả `emptyData` nếu chưa có file hoặc file hỏng.
- Hằng số tên file: `PRODUCTS`, `CUSTOMERS`, `ORDERS`, `RETURNS`, `STOCK_MOVEMENTS`.

Ví dụ:

```java
List<FoodProduct> products = FileHelper.load(FileHelper.PRODUCTS, new ArrayList<FoodProduct>());
FileHelper.save(FileHelper.PRODUCTS, products);
```
